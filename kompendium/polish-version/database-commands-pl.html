3 — Podgląd usług

SELECT * FROM services;

Pokazuje wszystkie 6 usług logopedycznych wstawionych przez seeder. Są statyczne — nigdy się nie zmieniają w trakcie działania aplikacji.

SELECT id, name FROM services ORDER BY id;

4 — Podgląd użytkowników

SELECT id, email, created_at FROM users;
Celowo pomijamy kolumnę password w SELECT — to hash bcrypt, nieczytelny dla człowieka, i nie ma powodu wypisywać go w terminalu.
Policz ilu użytkowników jest zarejestrowanych
SELECT COUNT(*) AS total_users FROM users;
Znajdź konkretnego użytkownika po emailu
SELECT id, email, created_at FROM users WHERE email = 'test@test.com';

5 — Podgląd wizyt

Wszystkie wizyty (surowe dane)
SELECT * FROM appointments ORDER BY date, time;
Wizyty z nazwą usługi i emailem użytkownika (JOIN)
SELECT
  a.id,
  u.email        AS uzytkownik,
  s.name         AS usluga,
  a.patient_name AS pacjent,
  a.date         AS data,
  a.time         AS godzina,
  a.mode         AS tryb,
  a.created_at   AS dodano
FROM appointments a
JOIN users    u ON u.id = a.user_id
JOIN services s ON s.id = a.service_id
ORDER BY a.date, a.time;

To najużyteczniejsze zapytanie — pokazuje wszystko w jednym wierszu. JOIN zastępuje numeryczne ID kluczy obcych prawdziwymi emailami i nazwami usług.

Wizyty konkretnego użytkownika
SELECT a.id, s.name AS usluga, a.date, a.time, a.mode
FROM appointments a
JOIN services s ON s.id = a.service_id
WHERE a.user_id = 1
ORDER BY a.date;
Ile wizyt ma każdy użytkownik
SELECT u.email, COUNT(a.id) AS liczba_wizyt
FROM users u
LEFT JOIN appointments a ON a.user_id = u.id
GROUP BY u.id, u.email
ORDER BY liczba_wizyt DESC;
Sprawdź czy limit 3 wizyt jest osiągnięty dla użytkownika
SELECT user_id, COUNT(*) AS total FROM appointments GROUP BY user_id;

6 — Podgląd sesji

SELECT id, user_id, last_activity FROM sessions ORDER BY last_activity DESC LIMIT 10;

Sanctum przechowuje sesje tutaj. user_id to NULL dla niezalogowanych gości, liczba dla zalogowanych użytkowników. last_activity to znacznik czasu Unix.

Zamień timestamp last_activity na czytelną datę
SELECT id, user_id, FROM_UNIXTIME(last_activity) AS ostatnia_aktywnosc
FROM sessions ORDER BY last_activity DESC LIMIT 5;

7 — Struktura tabeli

Sprawdź jakie kolumny ma tabela
DESCRIBE appointments;
DESCRIBE users;

Pokazuje nazwy kolumn, typy danych, czy akceptują NULL i wartości domyślne. Przydatne do weryfikacji że migracja wykonała się poprawnie.

8 — Usuwanie danych testowych

Te komendy trwale usuwają dane. Używaj tylko podczas developmentu, nigdy na produkcji.
Usuń konkretną wizytę po ID
DELETE FROM appointments WHERE id = 3;
Usuń wszystkie wizyty konkretnego użytkownika
DELETE FROM appointments WHERE user_id = 1;
Usuń konkretnego użytkownika (najpierw usuń jego wizyty)
DELETE FROM appointments WHERE user_id = 2;
DELETE FROM users WHERE id = 2;
Wyczyść wszystkie wizyty i zresetuj licznik auto-increment
TRUNCATE TABLE appointments;
Pełny reset (wyczyść użytkowników i wizyty — zostaw usługi)
SET FOREIGN_KEY_CHECKS = 0;
TRUNCATE TABLE appointments;
TRUNCATE TABLE users;
TRUNCATE TABLE sessions;
SET FOREIGN_KEY_CHECKS = 1;
FOREIGN_KEY_CHECKS = 0 tymczasowo wyłącza sprawdzanie kluczy obcych żeby można było truncatować tabele w dowolnej kolejności. Zawsze włącz ponownie po zakończeniu.

9 — Historia migracji

SELECT * FROM migrations ORDER BY id;

Laravel zapisuje tutaj każdą wykonaną migrację. Jeśli migracji nie ma na tej liście, oznacza to że nie została jeszcze zastosowana.

10 — Skróty Artisan (z terminala, nie z konsoli MySQL)

Te komendy wpisujesz w terminalu (nie w MySQL), z folderu p-laravel/app:

KomendaCo robi
php artisan migrate:statusPokazuje które migracje zostały wykonane, a które nie
php artisan migrate:fresh --seedUsuwa wszystkie tabele, tworzy je od nowa, uruchamia seedy — pełny reset
php artisan db:table usersPokazuje strukturę kolumn tabeli users
php artisan db:table appointmentsPokazuje strukturę kolumn tabeli appointments
php artisan tinkerInteraktywna konsola PHP — uruchamiaj kod Laravel/Eloquent na żywo
Przykłady Tinker (uruchamiane wewnątrz php artisan tinker)
// Policz wszystkich użytkowników
App\Models\User::count();

// Zobacz wszystkie wizyty
App\Models\Appointment::with('service','user')->get();

// Znajdź wizyty użytkownika o ID 1
App\Models\Appointment::where('user_id', 1)->get();
Tinker to najszybszy sposób na jednorazowe zapytania bez otwierania MySQL. Wpisz exit żeby wyjść.
