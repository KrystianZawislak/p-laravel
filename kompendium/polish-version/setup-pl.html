ARTIKULA — Instrukcja uruchomienia

Laravel 13 + MySQL + Sanctum SPA  |  System rezerwacji wizyt logopedycznych

Wymagania

NarzędzieWersjaJak sprawdzić
PHP8.2+php -v
Composer2.xcomposer --version
MySQL8.0+mysql --version
Gitdowolnagit --version
Na Macu z Laravel Herd: używaj php85 zamiast php oraz php85 artisan zamiast php artisan. MySQL musisz zainstalować osobno przez Homebrew — Herd go NIE zawiera.

Krok 1 — Sklonuj repozytorium

1
Sklonuj i wejdź do projektu 
git clone https://github.com/KrystianZawislak/p-laravel.git
cd p-laravel/app

Wszystkie komendy php artisan i composer wpisujesz z folderu p-laravel/app.

Krok 2 — Zainstaluj paczki PHP

2
Pobierz paczki z composer.lock 
composer install

Pobiera wszystkie biblioteki PHP do folderu vendor/. Plik composer.lock w repo gwarantuje, że każdy dostanie dokładnie te same wersje paczek.

Krok 3 — Plik środowiskowy .env

3
Skopiuj przykładowy .env 
cp .env.example .env
4
Wygeneruj klucz aplikacji 
php artisan key:generate

Wpisuje unikalny sekretny klucz do pliku .env. Wymagany do szyfrowania sesji i ciasteczek.

5
Edytuj .env — ustaw połączenie z bazą danych

Otwórz plik .env w dowolnym edytorze i zmień te linie:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=artikula
DB_USERNAME=root
DB_PASSWORD=

SANCTUM_STATEFUL_DOMAINS=localhost,127.0.0.1,127.0.0.1:8000
DB_PASSWORD pozostaje puste jeśli zainstalowałeś MySQL przez Homebrew z domyślnymi ustawieniami (root bez hasła).
SANCTUM_STATEFUL_DOMAINS — mówi Sanctum które domeny traktować jako "zaufane" i inicjalizować dla nich sesję. Bez tej linii API zwraca błąd "Session store not set on request".

Krok 4 — Baza danych

6
Uruchom MySQL (Mac + Homebrew) 
brew services start mysql
7
Utwórz bazę danych 
mysql -u root -e "CREATE DATABASE artikula CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
8
Uruchom migracje i seed 
php artisan migrate --seed

Tworzy wszystkie 4 tabele i wstawia 6 usług logopedycznych z seederа. Żadnych użytkowników ani wizyt — tworzy się je przez aplikację.

Co to są migracje? Pliki PHP w database/migrations/ które opisują strukturę tabel. Zamiast pisać SQL ręcznie, piszesz PHP — Laravel tłumaczy to na SQL i wykonuje. Każda zmiana struktury bazy to osobny plik migracji — dzięki temu historia zmian jest w git.
Co to jest seed? Plik database/seeders/DatabaseSeeder.php który wstawia dane startowe — w tym projekcie 6 usług. Uruchamiasz go raz przy setup.

Krok 5 — Uruchom serwer

Opcja A — Tylko lokalnie (zalecane do developmentu)

php artisan serve

Otwórz w przeglądarce:

http://127.0.0.1:8000

Dostępne tylko z tego komputera. Nic nie jest widoczne w sieci.

Opcja B — Dostęp z innych urządzeń w tej samej sieci Wi-Fi

php artisan serve --host=0.0.0.0 --port=8000

Znajdź swój lokalny adres IP:

ipconfig getifaddr en0

Następnie wejdź z dowolnego urządzenia w tej samej sieci Wi-Fi:

http://[TWÓJ-IP]:8000

Przykład: http://172.20.10.5:8000

Czy połączenie sieciowe jest bezpieczne?

CoStatusWyjaśnienie
Ostrzeżenie "Niezabezpieczona" w przeglądarceNORMALNESerwer deweloperski używa HTTP, nie HTTPS. Brak certyfikatu SSL. To oczekiwane na localhost.
Dane widoczne w sieci lokalnejTAKBez HTTPS ruch między telefonem a laptopem jest nieszyfrowany w sieci Wi-Fi.
Dostępny z internetuNIE192.168.x.x i 172.x.x.x to prywatne zakresy IP — nie można się pod nie podłączyć z zewnątrz routera.
Bezpieczny do demo i testówTAKNa zaufanej sieci prywatnej (dom, własny hotspot) — całkowicie w porządku. Nie używaj prawdziwych haseł.
Nigdy nie uruchamiaj --host=0.0.0.0 na publicznym Wi-Fi (kawiarnia, lotnisko). Twoja aplikacja byłaby widoczna dla wszystkich w tej sieci.
Do testów mobilnych na własnym hotspocie lub sieci domowej — całkowicie bezpieczne.

Uruchom automatyczne testy

php artisan test

Oczekiwany wynik: 15 passed. Testy używają bazy SQLite w pamięci — nie dotykają Twojego MySQL.
