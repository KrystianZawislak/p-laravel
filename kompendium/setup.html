ARTIKULA — Setup Guide

Laravel 13 + MySQL + Sanctum SPA  |  Speech therapy booking system

Requirements

ToolVersionHow to check
PHP8.2+php -v
Composer2.xcomposer --version
MySQL8.0+mysql --version
Gitanygit --version
On Mac with Laravel Herd: use php85 instead of php and php85 artisan instead of php artisan. MySQL must be installed separately via Homebrew — Herd does NOT include MySQL.

Step 1 — Clone the repository

1
Clone and enter the project 
git clone https://github.com/KrystianZawislak/p-laravel.git
cd p-laravel/app

Step 2 — Install PHP dependencies

2
Install packages from composer.lock 
composer install

This downloads all PHP packages into the vendor/ folder. The composer.lock file in the repo guarantees everyone gets the exact same package versions.

Step 3 — Environment file

3
Copy the example .env file 
cp .env.example .env
4
Generate the application key 
php artisan key:generate

This writes a unique secret key into your .env file. Required for sessions and encryption.

5
Edit .env — set database connection

Open .env in any text editor and update these lines:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=artikula
DB_USERNAME=root
DB_PASSWORD=

SANCTUM_STATEFUL_DOMAINS=localhost,127.0.0.1,127.0.0.1:8000
DB_PASSWORD is empty if you installed MySQL via Homebrew with default settings.

Step 4 — Database setup

6
Start MySQL (Mac + Homebrew) 
brew services start mysql
7
Create the database 
mysql -u root -e "CREATE DATABASE artikula CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
8
Run migrations + seed initial data 
php artisan migrate --seed

This creates all 4 tables (users, services, appointments, personal_access_tokens) and inserts the 6 therapy services from the seeder. No user accounts are created — those are made through the app.

Step 5 — Run the server

Option A — Local only (recommended for development)

php artisan serve

Open in browser:

http://127.0.0.1:8000

Only accessible from this computer. Nothing exposed to the network.

Option B — Network access (same Wi-Fi, for mobile testing)

php artisan serve --host=0.0.0.0 --port=8000

Find your local IP address:

ipconfig getifaddr en0

Then open on any device on the same Wi-Fi:

http://[YOUR-LOCAL-IP]:8000

Example: http://172.20.10.5:8000

Network mode — Is it secure?

WhatStatusExplanation
"Not secure" warning in browser WARNING Normal. The dev server uses HTTP, not HTTPS. No SSL certificate. This is expected on localhost.
Data visible on local network YES Without HTTPS, traffic between your phone and laptop is unencrypted on the Wi-Fi network.
Accessible from the internet NO 192.168.x.x and 172.x.x.x are private IP ranges. Not reachable outside your router.
Safe for demos / testing YES On a trusted private network (home / hotspot) this is fine. Do not use real passwords.
Never run --host=0.0.0.0 on a public Wi-Fi (cafe, airport). Your app would be visible to everyone on that network.
For mobile demos on your own hotspot or home network: completely fine.

Run automated tests

php artisan test

Expected result: 15 passed. Tests use an in-memory SQLite database — they do not touch your MySQL data.
