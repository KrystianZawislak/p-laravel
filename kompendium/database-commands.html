ARTIKULA — Database Commands

MySQL commands for inspecting and managing data during development

1 — Connect to MySQL

Open MySQL shell
mysql -u root artikula

You are now inside the MySQL shell. The prompt changes to mysql>. All SQL commands from this point end with ;.

To exit
exit
On Mac with Homebrew MySQL: if you get "Access denied", try mysql -u root -p artikula and press Enter when asked for password (empty password).

SHOW TABLES;

The tables we care about: users, services, appointments. The rest are created by Laravel automatically and are not used by our app logic.

3 — View services

SELECT * FROM services;

Shows all 6 therapy services inserted by the seeder. These are static — they never change at runtime.

SELECT id, name FROM services ORDER BY id;

4 — View users

SELECT id, email, created_at FROM users;
We deliberately omit password from the SELECT — it's bcrypt hash, not readable, and there's no reason to print it to the terminal.
Count how many users are registered
SELECT COUNT(*) AS total_users FROM users;
Find a specific user by email
SELECT id, email, created_at FROM users WHERE email = 'test@test.com';

5 — View appointments

All appointments (raw)
SELECT * FROM appointments ORDER BY date, time;
Appointments with service name (JOIN)
SELECT
  a.id,
  u.email        AS user,
  s.name         AS service,
  a.patient_name,
  a.date,
  a.time,
  a.mode,
  a.created_at
FROM appointments a
JOIN users    u ON u.id = a.user_id
JOIN services s ON s.id = a.service_id
ORDER BY a.date, a.time;

This is the most useful query — shows everything in one row. The JOIN replaces the numeric foreign key IDs with the actual email and service name.

Appointments for a specific user
SELECT a.id, s.name AS service, a.date, a.time, a.mode
FROM appointments a
JOIN services s ON s.id = a.service_id
WHERE a.user_id = 1
ORDER BY a.date;
Count appointments per user
SELECT u.email, COUNT(a.id) AS appointment_count
FROM users u
LEFT JOIN appointments a ON a.user_id = u.id
GROUP BY u.id, u.email
ORDER BY appointment_count DESC;
Check if the max-3 limit is reached for a user
SELECT user_id, COUNT(*) AS total FROM appointments GROUP BY user_id;

6 — View sessions

SELECT id, user_id, last_activity FROM sessions ORDER BY last_activity DESC LIMIT 10;

Sanctum stores sessions here. user_id is NULL for unauthenticated visitors, a number for logged-in users. last_activity is a Unix timestamp.

Convert last_activity timestamp to readable date
SELECT id, user_id, FROM_UNIXTIME(last_activity) AS last_seen
FROM sessions ORDER BY last_activity DESC LIMIT 5;

7 — Describe table structure

See what columns a table has
DESCRIBE appointments;
DESCRIBE users;

Shows column names, data types, whether they allow NULL, and default values. Useful to verify the migration ran correctly.

8 — Delete test data

These commands permanently delete data. Only use during development, never on production.
Delete a specific appointment by ID
DELETE FROM appointments WHERE id = 3;
Delete all appointments for a specific user
DELETE FROM appointments WHERE user_id = 1;
Delete a specific user (remove their appointments first)
DELETE FROM appointments WHERE user_id = 2;
DELETE FROM users WHERE id = 2;
Wipe all appointments and reset auto-increment counter
TRUNCATE TABLE appointments;
Full reset (wipe all users and appointments — keep services)
SET FOREIGN_KEY_CHECKS = 0;
TRUNCATE TABLE appointments;
TRUNCATE TABLE users;
TRUNCATE TABLE sessions;
SET FOREIGN_KEY_CHECKS = 1;
FOREIGN_KEY_CHECKS = 0 temporarily disables constraint checking so you can truncate in any order. Always re-enable it after.

9 — Check migration history

SELECT * FROM migrations ORDER BY id;

Laravel records every migration that has been run here. If a migration is missing from this list, it means it hasn't been applied yet.

10 — Artisan shortcuts (from terminal, not MySQL shell)

These commands are typed in the terminal (not inside MySQL), from the p-laravel/app folder:

CommandWhat it does
php artisan migrate:statusShows which migrations have been run and which haven't
php artisan migrate:fresh --seedDrops all tables, recreates them, runs seeders — full reset
php artisan db:table usersShows column structure of the users table
php artisan db:table appointmentsShows column structure of the appointments table
php artisan tinkerPHP REPL — run Laravel/Eloquent code interactively
Tinker examples (run inside php artisan tinker)
// Count all users
App\Models\User::count();

// See all appointments
App\Models\Appointment::with('service','user')->get();

// Find appointments for user ID 1
App\Models\Appointment::where('user_id', 1)->get();
Tinker is the fastest way to run one-off queries without opening MySQL. Type exit to leave.
